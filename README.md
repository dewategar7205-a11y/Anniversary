# 💕 Panduan Web Anniversary – Dewa & Risma

## Cara Membuka Website
Cukup **double-click** file `index.html` untuk membuka di browser.
> Tidak butuh internet (kecuali untuk load Google Fonts).

---

## 🎬 Cara Menambahkan VIDEO

Simpan video di: `assets/videos/video.mp4`

> Format: `.mp4` (paling kompatibel di semua browser)

---

## 🎵 Cara Menambahkan MUSIK

Simpan file musik M4A yang boleh kamu gunakan sebagai `assets/music/our-song.m4a`.
Untuk browser yang tidak mendukung codec AAC di M4A, sediakan juga MP3 sebagai
`assets/music/our-song.mp3` untuk fallback.
Saat website dipublikasikan, pastikan file tersebut ikut diunggah dengan struktur folder yang sama.
Klik tombol musik di pojok kanan atas untuk memutar atau menjeda lagu.

> Browser biasanya tidak mengizinkan musik berputar otomatis sebelum ada interaksi pengguna.
> Jika file belum tersedia, tombol akan menampilkan pemberitahuan.

## 💡 Tips Navigasi Website

| Aksi | Cara |
|------|------|
| Lanjut halaman | Klik tombol "Lanjut →" atau tekan `→` / `↓` di keyboard |
| Kembali | Klik "← Kembali" atau tekan `←` / `↑` |
| Navigasi cepat | Klik titik-titik di bawah halaman |
| Swipe (HP) | Geser kiri/kanan di layar |
| Perbesar foto | Klik foto mana saja |
| Tutup foto besar | Klik di mana saja atau tekan `Esc` |
| Kejutan 🎊 | Klik tombol "Klik untuk Kejutan!" di halaman terakhir |
